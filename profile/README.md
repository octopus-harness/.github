# Octopus Harness 🐙

A lightning-fast, local, TUI and CLI-driven agentic suite built for modern coding agents.

[Octopus Harness](https://github.com/octopus-harness) is an open-source organization centered on [`octopus`](https://github.com/octopus-harness/octopus). It exists to give developers and autonomous coding agents a fast, predictable, terminal-native environment without cloud overhead or bloated tooling.

## Philosophy

Not a cloud wrapper, not a heavy IDE extension, and not a slow browser dashboard. Octopus Harness is a local-first foundation built for the terminal, where modern coding agents actually operate.

* **Local-First Execution**: Everything runs directly on your machine. Your code stays on your disk, your context stays under your control, and round-trip latency stays near zero.
* **TUI and CLI Together**: Move between a keyboard-driven terminal UI for live agent oversight and a composable CLI for scripts, automation, and headless runs.
* **Built for Coding Agents**: Designed specifically around the needs of modern coding agents: fast file operations, structured tool use, tight feedback loops, and clean session management.
* **Modular by Design**: Centered on `octopus` as the core harness, with room for specialized tools, local model integrations, and custom workflows to grow around it.

## Core Repository

* [`octopus-harness/octopus`](https://github.com/octopus-harness/octopus): The flagship local TUI and CLI agentic suite.

## Getting Started

Clone the core repository to inspect the codebase, track releases, or run it locally:

```bash
git clone https://github.com/octopus-harness/octopus.git
cd octopus
```

See the [`octopus` repository](https://github.com/octopus-harness/octopus) for build instructions, configuration options, and CLI usage.
